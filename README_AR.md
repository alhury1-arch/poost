# الحوري – حسابات بيع كروت الواي فاي

## محتويات المشروع
- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- قاعدة SQLite محلية لحفظ الأحداث دون إنترنت.
- WorkManager لإعادة محاولة المزامنة عند عودة الاتصال.
- مستقبل Google Apps Script لتسجيل الأحداث في Google Sheets.
- GitHub Actions لبناء APK تجريبي تلقائيًا.

## بناء APK
ارفع محتويات المجلد إلى المستودع `alhury1-arch/poost` على الفرع `main`.
بعد الرفع افتح Actions ثم Build Android APK، وانتظر نجاح البناء، ثم نزّل Artifact باسم:
`Alhury-WiFi-Accounts-debug`.

## إعداد Google Sheets
1. أنشئ جدول بيانات رئيسيًا في حساب Google المالك.
2. افتح Extensions > Apps Script.
3. انسخ محتوى `google-apps-script/Code.gs`.
4. ضع معرّف الجدول في `MASTER_SHEET_ID`.
5. انشره Web App، واضبط التنفيذ بحساب المالك وسياسة الوصول المناسبة.
6. ضع رابط النشر في إعدادات التطبيق.

## حالة الإصدار
هذه نسخة تأسيسية قابلة للبناء وليست نظامًا محاسبيًا إنتاجيًا مكتملًا. نموذج المزامنة يستقبل سجل أحداث ويمنع تكرار معرف الحدث، لكنه لا ينشئ بعد ملفات موزعين منفصلة أو يطبق دورة إقفال شهرية أو صلاحيات دخول آمنة. كما أن أدوار الواجهة الحالية تجريبية. يجب إكمال هذه الوظائف واختبارها قبل إدخال بيانات مالية حقيقية.
